# WF-003 — Caso adicional: resumen operativo diario

Actividad extra si el grupo avanza rápido.

**Trigger:** Schedule.

**Flujo:** API → citas del día → agrupación por sede/estado/especialidad → resumen → Gmail.

El correo de laboratorio contiene total por sede; `APPROVED`/`COMPLETED`/`NO_SHOW`/`CANCELLED`; distribución por especialidad e incidencias de API. No requiere información privada real.
